## ✨ Key Features

### 🔍 Automatic PII Detection
The app uses built-in recognition patterns to find common personal information across all your documents. It identifies names, phone numbers, email addresses, national IDs, birthdates, and more – without any manual marking needed.

### 👁️ Masking Preview
Before anything is changed, you see exactly what will be hidden. The app shows you a highlighted preview of every piece of detected personal data. You control what gets masked and what stays visible.

### ✋ Human Review Override
You can manually select or deselect any field the app detects. This isn't a "set and forget" tool – it respects your judgment about which data is sensitive for your specific context.

### 🔄 CSV Codebook for Restoration
The tool generates a CSV (Comma Separated Values) file that acts as a key. It records what was hidden and how. If you need to view the original data again later, this codebook allows you to reverse the masking process.

### 🔐 100% Local Processing
Your files never leave your computer. There's no cloud component, no telemetry, no background uploads. For privacy, the app operates entirely in your local environment.

## 📝 Step-by-Step Usage Guide

### Step 1: Launch the Application
Double-click the downloaded file to open the tool. You'll see a clean, friendly interface with a button to select your document.

### Step 2: Choose Your File
Click "Select File" or "Browse" to find your PDF, Word, Excel, TXT, or Markdown document. Navigate to the correct folder and choose the file you want to process.

### Step 3: Review Detected Information
The app immediately scans your document. Take your time reviewing the highlighted sections – this is your chance to add or remove any data you want hidden. Pay attention to anything that looks like a name, number, or identifier.

### Step 4: Configure Masking Options (Optional)
Choose how you want masked data to appear. You might prefer dashes (-----), asterisks (*****), or blank spaces. The choice affects the output format of your deidentified document.

### Step 5: Generate the Deidentified Version
Click "Process" or "Apply Masking" to create your new document. The saved file will have the same content, but with all selected personal information hidden.

### Step 6: Save the CSV Codebook
You'll be prompted to save the codebook file. Store this in a secure location – anyone who has it can restore the original data. Keep it separate from the deidentified document for maximum safety.

### Step 7: Verify Your Output
Open the new document to confirm everything looks correct. Check that all sensitive information is properly hidden and the document remains readable and useful.

## 🛠️ Troubleshooting Common Issues

### Problem: App won't open after download
**Solution:** Make sure you've fully extracted the downloaded folder (if it came as a ZIP). Also check that you haven't placed the app in a protected system folder like Program Files without admin rights.

### Problem: Can't see some detected data in preview
**Solution:** Try zooming in or scrolling through the entire document preview pane. The detection works on the whole file, but some fields might be on pages far from where you're looking.

### Problem: The CSV codebook won't restore my data
**Solution:** Ensure you're using the exact same version of the application to restore data that you used to create it. Also verify the codebook hasn't been opened and saved with different formatting by another program.
